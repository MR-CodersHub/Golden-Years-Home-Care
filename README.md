# GoldenYears Home Care 🌿

Certified Aging-in-Place Handyman & Senior Safety Solutions.

A modern, responsive, and accessible web application designed for senior safety, home modifications (grab bars, wheelchair ramps, stair handrails, bathroom walk-in conversions), and family care coordination.

## 🚀 Features

- **Responsive & Accessible Design**: Built with high contrast readability, senior-friendly typography, and full mobile/tablet/desktop responsiveness.
- **Theme & Direction Support**: Integrated Light/Dark mode switcher and RTL (Right-to-Left) language support.
- **Interactive Multi-Step Booking**: In-home safety assessment scheduling and quote calculation.
- **Family Dashboard**: Client portal for tracking scheduled home visits, safety reports, and care notes.
- **Rich Pages**:
  - `index.html`: Main landing page with hero carousel, service highlights, testimonials, and booking flow.
  - `pages/home2.html`: Alternate landing page layout.
  - `pages/about.html`: Team, certifications (CAPS), mission, and values.
  - `pages/services.html` & `service-details.html`: Detailed safety modification packages.
  - `pages/pricing.html`: Transparent tiers and cost estimators.
  - `pages/blog.html` & `blog-details.html`: Senior safety journal and tips.
  - `pages/contact.html`: Contact forms, emergency line, and service area map.
  - `pages/dashboard.html`: Family and caregiver portal.
  - `pages/auth.html`: User login and registration.
  - `pages/404.html` & `maintenance.html`: System pages.

## 🛠️ Tech Stack

- **HTML5** (Semantic & Accessible markup)
- **Vanilla CSS3** (Custom design tokens, CSS variables, responsive grid/flexbox)
- **Vanilla JavaScript** (Interactive components, carousel, theme toggle, modals, family dashboard)

## 💻 Getting Started

Simply open `index.html` in any modern web browser or serve via a local static server:

```bash
# Using VS Code Live Server or Python HTTP Server:
python -m http.server 8000
```
